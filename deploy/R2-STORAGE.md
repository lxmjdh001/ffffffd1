# APK / PWA 文件统一存储到公开 R2

安装包、上传的 PWA 图标、通知推送图片、回流图片/视频均存储到 R2。
默认复用现有 `PAGE_IMAGE_R2_*` 公开图片桶，无需新建私有桶。
账号、配置、订阅、余额和文件元信息仍在数据库中。PWA 是动态网页，
不需要额外生成一个 PWA 文件；默认图标仍由代码生成。
用户填写的第三方 HTTPS 图片或 APK 链接不会被自动抓取复制。

## 配置

已有完整 `PAGE_IMAGE_R2_*` 且没有旧 S3/远程存储配置时，自动复用图片桶，
无需新增密钥。也可在私有环境文件中独立配置以下四项：

```dotenv
R2_ENDPOINT=https://<account>.r2.cloudflarestorage.com
R2_ACCESS_KEY=<仅后端使用>
R2_SECRET_KEY=<仅后端使用>
R2_BUCKET=<已有公开桶名称>
```

独立配置不能与 `S3_ENDPOINT` 或 `REMOTE_STORAGE_URL` 同时使用。
复用公开桶，不更改桶的公开访问、CORS、域名或其他项目数据。
密钥仅在服务端使用；公开读取不代表允许匿名上传、覆盖或删除。

## 迁移已有文件

1. 停止上传和应用写入，停止服务，备份数据库和 `data`。
2. 加载环境，构建 `go build -o bin/d1apk ./cmd/server`。
3. 运行 `bin/d1apk migrate-r2`，全部成功后再启动服务。
4. 验证旧分享链接、下载、PWA 图标和素材；原本地文件保留，不自动删除。

迁移先上传，再读取 R2 文件校验长度和 SHA256，校验成功后才切换图片/素材引用。
安装包标识、分享链接不变，数据库图片二进制迁移后清空，仅保存对象键。
迁移可重试；失败时不要切回旧版本启动，因为部分素材可能已成功切换到 R2。
已有其他 S3/远程下载节点的安装包须先按原键复制到本地暂存并校验，再迁移。

## 访问与隔离

文件目录按 R2 账号、桶和 `APP_URL` 隔离：
`d1apk/files/<环境标识>/{apps,pwa-icons,push-images,return-flow}/...`。
APP_URL 改变时需要迁移对应目录，不能直接切换旧存储。

原平台分享链接、计量/计费、鉴权和 Range 下载流程继续保留。
公开桶中的原始对象 URL 可以直接读取，不经过平台统计、额度或停用检查；
原平台图标/素材地址继续执行账户状态和归属检查，但原始 URL 不受限。
对象删除后，CDN 或终端缓存也可能继续保留一段时间。

R2 上传失败会报错，不悄悄把新文件保存回本地。处理中的临时文件使用后清理。
媒体登记在 `r2_media_objects`，后台仅清理超过 24 小时、不再被引用的本环境
对象；安装包清理也只列举本环境的 `apps/` 子目录，不碰其他项目文件。
无任何 R2 或旧 S3/远程存储配置的环境仍兼容本地模式。
