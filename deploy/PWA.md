# 网页转 PWA 与通知推送

控制台的“网页转 PWA”用于设置应用名称、HTTPS 网页地址、简介、图标与主题色。每个客户独立管理自己的应用；应用数量受当前套餐的应用数量上限约束，独立于安装包列表计数。图标支持最多 2 MiB 的 PNG/JPEG，校验像素后统一处理为 512 像素 PNG，存在数据库中，不改变现有 APK 或 R2 页面图片存储。

安装入口为 `APP_URL/p/{slug}/`，桌面应用启动到同目录 `launch`。Manifest ID、scope、Service Worker 都限定在该应用目录。应用关闭、删除或所属账户停用后，公开页面和资源不可访问；客户登录后台后仍能查看暂停应用的图标。安装页和应用页面根据浏览器语言提供中文或英文提示。

目标网页在独立来源的全屏 iframe 中加载。服务器不抓取、代理或改写目标网页。与参考 PWA 一样，允许 HTTPS 网页跳转到 www、登录、支付等其他 HTTPS 域名，并允许用户主动点击后跳转顶层窗口；平台所有页面继续使用 `frame-ancestors 'none'` 和 `X-Frame-Options: DENY`，防止目标跳回平台后取得同源页面控制权。目标仍必须允许 iframe 嵌入；登录、支付、弹窗等功能仍受目标网站和浏览器规则约束。开发环境只额外允许填写的精确本地 HTTP 来源。关闭网络时只显示连接提示，不承诺目标网页离线运行。iPhone/iPad 用户需要添加到主屏幕后打开应用，再主动点击通知授权按钮。

## PWA 安装与 Play 按钮

商店、自定义图片、原有安装页共用安装状态处理。仅收到浏览器 `appinstalled` 成功事件后，将安装按钮改为 `Play`；接受安装弹窗、取消或失败不会提前切换。Vue 异步挂载、语言更新及挽留安装按钮也会同步，保留原按钮图标与功能监听。仅 APK/W2A 模式继续下载 APK，不改成 Play。

安装弹窗发起后，商店主图标、挽留弹窗图标及原有安装页图标缩小至 68%，原位置显示蓝色旋转圆环；图标占位、按钮文案和页面布局不变。接受安装后保持等待，成功、取消、异常或新的安装提示会清理动画；无结果时最多等待 60 秒，不据此判断成功，后续成功事件仍可切成 Play。遵循系统减少动态效果设置。自定义图片模板没有固定应用图标，不额外添加图标或按钮动画；APK-only、手动安装引导及应用启动页不显示该动画。

安装确认以当前域名的本地存储及 `/p/{slug}/` 区分，刷新后保留最后确认状态，不跨应用/域名复用；这是安装记录而不是通用的系统安装检测。浏览器再次发出 `beforeinstallprompt` 时清除过期记录并恢复原安装文案；本地存储不可用时仍可在当前页面切换。不支持安装成功事件的平台继续原有手动安装引导，不伪造成功。

Play 使用当前域名的 `/p/{slug}/launch`，斗篷入口也沿用复制时所选域名，不直跳客户外部 URL。在已有独立应用窗口内直接进入启动页；浏览器内通过用户主动点击的 `noopener` 新窗口导航，支持捕获的浏览器可唤起已安装 PWA，其他情况在浏览器打开同一启动入口。实际系统窗口行为受浏览器及用户设置限制。不会自动打开、请求通知权限、改变 APK 下载计费或修改收款配置；无数据库迁移。

## 通知

PWA 与 APK 的 Google Play/自定义详情页共用 23 种语言选择、语言编辑选项卡与优先级组件。按浏览器语言精确或前缀匹配；未匹配时按所选顺序兜底。APK 各语言的标题、介绍、按钮、图片等独立保存在既有详情页 JSON 中，旧单语言配置无需迁移且原样保留，旧商店/简洁模板继续使用原有语言按钮。

PWA 复制链接使用右侧域名选择抽屉。安装页在已验证且有权限的下载域名及斗篷域名上运行，内部资源、安装接口和图标沿用当前域名；控制台管理 API 不向下载域名开放。创建表单按钮居中，预览列不再遮挡提交区。iOS、自动 APK、嵌入网页、桌面二维码与浏览器引导分别按所选模板及参考 PWA 行为处理。

每个 PWA 创建独立 VAPID 身份，私钥和浏览器订阅凭证使用既有 `APP_SECRET` 加密保存。首次授权仅由用户点击触发，支持订阅和主动退订。已授权用户打开安装页或桌面应用时，自动同步当前浏览器订阅，更新变化的推送地址；使用原订阅凭证更新原记录，不重复触发首次订阅推送。主动退订后保留本地关闭状态，刷新页面不会自动重新订阅；服务端使用订阅行锁区分自动续期与主动开启，其他窗口延迟完成的自动续期不能恢复已退订记录。公开订阅写接口检查同源请求、频率、密钥格式和浏览器推送服务地址；退订和事件回报分别使用独立能力凭证。控制台报告不包含浏览器订阅端点或密钥。

“通知推送”支持立即发送、在指定时间发送、首次订阅后延迟 0–43200 分钟发送。固定时间按管理员当前浏览器时区输入，提交为带时区的时间；服务器存储和执行使用 UTC。首次订阅规则只面向之后新增的订阅，持续生效直到停止。可以按国家或地区筛选，无法识别地区的订阅标为未知。

任务与每设备投递记录保存在现有数据库中，无需新增消息队列服务。控制端启动两条发送工作协程；分批展开受众，使用任务锁、独占租约和投递唯一索引，服务重启后继续处理。任务创建使用用户级幂等键，相同请求重试返回原任务，变更请求内容则拒绝复用。临时故障最多尝试 5 次，在首次计划发送时间后的 24 小时内退避重试。404/410 仅使对应旧版本订阅失效，避免过期响应覆盖已经续订的凭证。

“已发送”表示推送服务接受消息；“已展示”和“已点击”分别由设备回报，每种事件只计一次。取消会阻止尚未开始的发送，已进入网络请求的消息可能已经送达。每条 push 都展示通知，符合苹果 `userVisibleOnly` 要求；同一投递使用稳定的通知标签和 `renotify:false`，由系统替换尚存在的同标签通知。通知点击按配置的 HTTPS 地址打开或聚焦已有窗口，包括平台自身的下载、分流和斗篷链接。Web Push 不提供端到端的恰好一次保证；用户已清除通知后再次收到重试时，系统仍可能重新展示，需要真机确认最终提醒行为。

## 通知模板、图片与按钮

“通知模板”可保存常用的标题、正文、点击链接、通知图标、大图和操作按钮，支持搜索、新建、编辑、删除，并在同一客户的不同 PWA 中复用。模板名称仅供后台管理，不显示给接收通知的用户。选用模板后可以修改本次发送内容；创建任务时保存完整内容快照，立即发送、定时发送和首次订阅规则均使用该快照。后续编辑或删除模板不会改变已有任务，相同幂等请求重试也返回原任务。

通知图标和大图均可填写 HTTPS 图片链接或直接上传。图标留空时使用应用图标；大图为选填项。通知图片上传支持 PNG、JPEG、WebP，每次一张、原文件最多 2 MiB，尺寸不超过 4096 × 4096 且总像素不超过 1600 万。服务器校验实际图片内容后统一存为 PNG：通知图标处理为 512 × 512，大图保留比例、最长边不超过 1600 像素，转换结果超过 5 MiB 时拒绝保存。此上传入口独立于既有 PWA 应用图标上传规则。

模板的查询、编辑、删除和任务引用均校验当前所有者，客户不能访问或引用他人的模板。图片按所有者分别存储、去重和限制数量，不与其他客户共享去重记录；上传写接口要求登录及 CSRF 校验。每个客户最多保存 200 份模板、500 张通知图片。图片以随机 ID 的 `/pwa-push-assets/{id}.png` 地址公开提供给通知设备加载，URL 不含用户标识或原始文件名；资源仅在主站域名提供，所属账户停用后不再返回图片。持有该 URL 的设备可直接加载图片。

每条通知最多配置两个操作按钮，按钮名称为 1–40 字，每个按钮使用独立的 HTTPS 跳转地址。点击正文打开通知主链接，点击按钮打开对应地址；未知按钮或无效地址回退主链接。Service Worker 按浏览器报告的最大按钮数显示；不支持大图或按钮的设备仍显示基础通知，正文可正常点击。浏览器因不兼容富选项而拒绝展示时，移除大图和按钮后尝试基础通知；权限已拒绝时不作兼容重试，展示成功后才上报展示事件。所有点击继续使用原投递凭证计数，不按按钮重复增加点击数。

## APK 详情页文字混淆

APK 的 Google Play/自定义详情页可按语言开启“文字混淆”，默认关闭。可见应用名称及开发者/品牌名保持不变，DOM 文本穿插随机字符；服务端的 APK 标题回退内容也使用相同的显示效果。仅处理实际的文字节点，不处理图片中的文字，不改变下载按钮、链接、域名、语言匹配或计费。该功能不调用 AI 服务，不是加密、访问控制或审核通过保证；页面配置和可访问性信息仍可能包含原文。混淆片段使用零尺寸、脱离布局的元素并从辅助技术中隐藏，前端预览关闭开关后还原原文字。

## 落地页源码差异

APK、PWA 落地页和对应预览在 BODY 顶部加入每次渲染重新生成的随机英文字母注释及惰性 `template`。片段包含随机四角定位、1/2/3/5 像素尺寸、颜色、描边、圆角、CSS 变量名及属性顺序；样式和元素始终留在 `template.content`，不执行、不产生请求、不进入可见布局，也不影响点击。PWA 启动后的目标网页不添加此片段。

落地页根类名按用户和 APK/PWA 类型从 `APP_SECRET` 派生，跨刷新保持一致，不直接暴露内部用户 ID；APK 根样式选择器及旧 PWA 安装页的 CSS 同步使用该类名，前端功能使用固定数据标记，不依赖随机名称。不改变客户内容、语言匹配、斗篷所选域名、下载/安装、回流和账务逻辑。此功能只改变部分源码外观，不保证防关联、减少误封或通过第三方审核。

## 回流页

按参考 `pwa` 项目 `codex/pwa-lang-startup-fix` 的 `returnFlowConfig` 实现，在 PWA 编辑及安装包详情页设计中独立设置，默认关闭。PWA 仅在安装入口展示，与原项目保持一致，不在已打开的目标网页上覆盖弹窗；安装包支持 Google Play、商店和简洁三个详情页模板。

支持返回键、回到前台或两者触发；支持单次会话只展示一次，以及每次返回重复展示。单次显示按当前域名、路径和浏览器标签页隔离，刷新保持状态；浏览器禁用会话存储时，当前页面仍使用内存标记防止连弹。可配置标签、标题、描述、主按钮、关闭文案、50–100% 素材区域和全图模式。主按钮可继续浏览、下载/安装或跳转 HTTPS/站内地址；与参考项目兼容，继续浏览动作填写了地址时也打开该链接。安装动作直接复用已有 PWA 安装或安装包下载流程，不自动请求通知权限。

素材支持 PNG/JPEG/WebP、MP4/WebM/MOV/M4V，单文件最多 50 MiB，每账户最多 100 个或 500 MiB。图片限制 4096 边长及 1600 万像素并重新编码 PNG，视频检查容器标识，以原格式提供 Range/HEAD。上传需要登录与 CSRF，元数据按用户隔离和去重，文件保存在 `DATA_DIR/return-flow-assets`；备份和迁移节点时须同时保留该目录。随机公开资源 URL 可供页面加载；所属账户停用后资源停止返回。回流素材独立于 APK 私有文件、通知图片和 R2 页面截图。

安装包可开启“下载中断返回后显示”：只在下载已开始、页面失焦或隐藏后又恢复时触发，首次进入与没有中断的普通 focus 不触发；回流按钮自己发起的下载不再次触发同一提示。与参考实现一样，网页无法准确知道用户在浏览器原生风险提示中选择了取消还是继续。回流展示和按钮点击派发 `pwa-return-flow-view` / `pwa-return-flow-click` 浏览器事件，本次不新增展示收费，不改变下载完成后原有结算。

## 发布与验证

迁移 version 13 仅新增 `pwa_apps`、`pwa_push_subscriptions`、`pwa_push_tasks`、`pwa_push_deliveries`，保留原有用户、余额、订单、返利及账本。现有 `APP_URL` 必须是 HTTPS，现有 `APP_SECRET` 继续用于加密，应用密钥自动生成，无需客户手动配置。

迁移 version 14 仅新增 `pwa_push_templates`、`pwa_push_assets` 两张表，为 `pwa_push_tasks` 新增 `template_id`、`image`、`actions_json` 三列及对应索引。已有任务保留原内容、计划时间、状态和投递 ID，新按钮字段默认空数组，不改变已有订阅、投递、账户或账务记录。通知图片保存在现有数据库中，无需新增存储服务或消息队列配置。

本次迁移 version 15 仅新增 `return_flow_assets`，为 `pwa_apps` 新增默认 `{}` 的 `return_flow_json` 列；旧应用保持关闭，既有任务、订阅、用户和账务记录保留。安装包回流配置保存在既有详情页 JSON 中，不修改原始下载记录。

部署先备份数据库、数据目录与环境，在 PostgreSQL 克隆库演练，并比较旧表行摘要和字段。停止 D1 服务后再执行事务迁移，切换已校验的二进制和前端资源，仅重启 D1；失败恢复旧版本。Go/HTTP、独立 PostgreSQL、RFC8291 加密接收器、前端与 Service Worker 运行测试均不向真实客户发送通知。真实手机通知展示依赖用户授权、浏览器推送服务和设备系统设置。
