# Console languages

The homepage, authentication screens and console share `i18n.ts`. Supported
locales are English, Portuguese, German, French, Korean, Japanese, Simplified
Chinese, Traditional Chinese and Russian.

The original Simplified Chinese UI text is the stable message key. `source.json`
is generated by `node scripts/extract-locales.mjs`; `messages.json` contains the
eight translated catalogs. `reviewed.json` pins important navigation, payment
and homepage terminology. English copy was authored against the original UI;
other language drafts were produced locally with official Argos/OPUS models,
with important terminology overridden. Long-form translations can receive
further native-speaker editorial review. No translation service runs in the
browser or receives customer content.

The offline models were obtained from the official
[Argos package index](https://github.com/argosopentech/argospm-index). The OPUS-MT
work is credited to Jörg Tiedemann and Santhosh Thottingal, *OPUS-MT — Building
open translation services for the World* (EAMT 2020). Model licenses and credits
are supplied in their original package README files; no model weights or
Python dependencies are shipped with D1. Traditional Chinese was converted
with OpenCC and reviewed terminology overrides.

When adding UI copy, wrap developer-owned text in `t(...)`, extract the source
keys and add every translation. `npm run build` checks catalog coverage and
placeholder preservation. Never wrap arbitrary customer data in translation
calls. Default system plan names have an explicit allowlist; custom names stay
unchanged. Module-level labels use getters so language changes do not leave
stale text, and React views subscribe with `useLocale()`.

Manual choices are stored in `d1.locale` and override automatic selection.
Without a preference, `/api/config` supplies a country hint derived from the
existing trusted CDN/proxy chain. Unknown countries fall back to supported
browser languages, then English. The response is private and not cacheable.
No new geolocation service or paid API is needed. DNS-only requests without
a trusted country source use the browser-language fallback.

Ordinary numbers and dates follow the selected locale. USDT payment
instructions always use the exact canonical decimal amount, including all
six decimals on historical orders, and copying preserves the same value.
Language changes never alter payment identifiers, amounts, network settings,
receiving addresses, signatures, billing calculations or crediting logic.
